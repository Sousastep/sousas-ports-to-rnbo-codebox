# Max JS API

Reference for the API available within the `[js]`, `[jsui]`, `[v8]`, `[v8.codebox]`, and `[v8ui]` objects

Some classes and interfaces are only available with the v8 engine. For more information, refer to the [JavaScript Documentation](/userguide/javascript/#javascript-objects)

## Globals[](#globals)

ItemEngineDescription[console](/apiref/js/global-console/)v8The global `console` instance, the Max-console-backed `console` object exposed by the v8 runtime.[globalThis](/apiref/js/global-globalthis/)The "this" object in the context of JavaScript in Max. The object is the "this" within the context of any function you define that can be invoked from Max, as well as in your global code. See [jsthis](/apiref/js/jsthis/) for more details.[Jitter3DUtils](/apiref/js/global-jitter3dutils/)The global `Jitter3DUtils` interface, providing utility functions for 3D vector and matrix operations. See [Jitter3dUtilsInterface](/apiref/js/jitter3dutilsinterface/) for more details.[max](/apiref/js/global-max/)Singleton Max object to access and control the Max environment. See [Max](/apiref/js/max/) for more details. In addition to the properties and methods described here, you can also use the global Max object to call methods as defined in [Controlling Max with Messages](/userguide/controlling_max_with_messages/)[mgraphics](/apiref/js/global-mgraphics/)The global `mgraphics` instance, for rendering shapes and images in custom Max objects.[sketch](/apiref/js/global-sketch/)The global `sketch` instance, for drawing in custom Max objects with an OpenGL-backed drawing context.

## Functions[](#functions)

ItemEngineDescription[clearImmediate](/apiref/js/global-clearimmediate/)v8Cancels an immediate previously created with [setImmediate()](/apiref/js/global-setimmediate/).[clearInterval](/apiref/js/global-clearinterval/)v8Cancels an interval previously created with [setInterval()](/apiref/js/global-setinterval/).[clearTimeout](/apiref/js/global-cleartimeout/)v8Cancels a timeout previously created with [setTimeout()](/apiref/js/global-settimeout/).[cpost](/apiref/js/global-cpost/)Prints a message to the system console window. See [post()](/apiref/js/global-post/) for more details about arguments and formatting.[error](/apiref/js/global-error/)Prints a message to the Max console with a red tint. See [post()](/apiref/js/global-post/) for more details about arguments and formatting.[fetch](/apiref/js/global-fetch/)v8Fetches a resource over HTTP or HTTPS.[messnamed](/apiref/js/global-messnamed/)Sends a message to the named Max object.[post](/apiref/js/global-post/)Prints a representation of the arguments in the Max window.[queueMicrotask](/apiref/js/global-queuemicrotask/)v8Queues a microtask to run after the current task completes and before the next timer callback.[setImmediate](/apiref/js/global-setimmediate/)v8Schedules a callback to run on the next scheduler tick.[setInterval](/apiref/js/global-setinterval/)v8Schedules a callback to run repeatedly at a fixed interval.[setTimeout](/apiref/js/global-settimeout/)v8Schedules a one-shot callback to run after a delay.

ItemEngineDescription[AddressInfo](/apiref/js/addressinfo/)The local or remote endpoint of a socket, as returned by `address()`.[AttributeOptions](/apiref/js/attributeoptions/)Options accepted by the v8-only forms of [declareattribute](/apiref/js/jsthis/#declareattribute-attributename-options), describing how an attribute is typed, stored, and presented.[Console](/apiref/js/console/)The Max-console-backed `console` object exposed by the v8 runtime.
